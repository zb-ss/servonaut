# Security policy

## Report a vulnerability

Please report suspected security vulnerabilities through
[GitHub's private vulnerability reporting form](https://github.com/zb-ss/servonaut/security/advisories/new).
You can also open the repository's **Security** tab, select **Advisories**, and
choose **Report a vulnerability**.

Please keep vulnerability details and proof-of-concept code out of public issues,
pull requests, and discussions while the report is being investigated.

Include as much of the following as you can:

- The affected Servonaut version, installation method, and operating system.
- The affected feature and any configuration or permissions needed to reproduce
  the issue.
- Clear reproduction steps or a minimal proof of concept using test data.
- The expected and observed behavior, and the potential security impact.
- Relevant logs or screenshots with credentials, personal information, and
  infrastructure identifiers removed.

Never include live passwords, API tokens, private keys, or credential files.
Test only in environments you own or have permission to assess.

## Review and disclosure

Maintainers review reports privately and may ask for additional information to
reproduce and assess the issue. Please use the private report to coordinate any
fix and public disclosure.

For bugs without a security impact, use the
[public issue tracker](https://github.com/zb-ss/servonaut/issues).
